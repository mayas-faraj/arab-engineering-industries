# arab-engineering-industries

PHP/MySQL website and admin CMS for Arab Engineering Industries (itihad).

> **Archived, read-only.** Kept for reference; not maintained. Part of the legacy collection in [enterprise-archive](https://github.com/mayas-faraj/enterprise-archive).

## Stack

PHP, MySQL, JavaScript.

## Prerequisites

A PHP 5.x/7.x web server with MySQL. The database dump and `config.php` were removed; create your own `config.php` and schema.

## Running

This is an archive; there is no staging/production deployment. For local inspection:

Serve the repo root with Apache/PHP and point a new `config.php` at an empty database.

## History notes

Rewritten before publication: `node_modules`, build output, database dumps, `.env`/`config.php` credential files and oversized binaries were removed from every commit. The default branch is `master`; the last commit snapshots work that was never committed.
